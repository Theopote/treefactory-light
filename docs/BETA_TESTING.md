# Treefactory Light 0.1.0-beta.1

## 环境与安装

- Minecraft **26.3**，Fabric Loader **0.19.5+**，Fabric API **0.161.0+26.3**，Java **25**。
- 将 `build/libs/treefactory-light-0.1.0-beta.1.jar` 与匹配版本的 Fabric API 放入 `mods`。
- 多人游戏需要客户端与服务器同时安装；本版为创造模式建造工具。
- 主代码全部位于 `src/main/java/com/treefactory/light/`，客户端专用类仅由客户端入口和客户端 Mixin 加载。

## 操作

1. 在创造物品栏“工具与实用物品”中获取树木杖，或执行 `/give @s treefactory-light:tree_wand`。
2. 手持树木杖对准地面，观察世界中的全息预览。
3. **Shift + 右键**打开侧栏。四种内置树形与用户预设集中在“预设库”，每行两张图；悬停可查看树名和树种，点击后参数自动载入生成器。生成器可调整 17 种树冠形状、三个基因参数、树冠范围、吸引点密度与管道指数（2.5–3.0）。打开时锁定放置点。
4. 左侧内容可滚动；展开“材质调色盘”切换主干、粗枝、细枝、主叶、点缀叶与装饰方块。叶片比例可循环选择 80/15/5、65/25/10、95/5/0。右侧预览可拖动旋转、滚轮缩放，默认略微俯视。
5. 点击“放置树木”，或关闭侧栏后右键地面放置。
6. **Shift + 滚轮**切换 S / M / L / Giant；**Shift + 左键**或侧栏“撤销”还原上一次构建。
7. 修改预设参数后输入新名称并保存，会在预设库新增一张预览图。当前选中的预设卡片在悬停时显示旋转模型。

## 数据和运行边界

- JSON 与 128×128 PNG 缩略图：`.minecraft/config/treefactory_light/presets/`（开发环境为 `run/config/…`）。旧视角缩略图不再使用；预设库中的缩略图按需重新生成。
- JSON 当前为 1.1，新增 canopy 与六角色 palette；旧版 1.0 预设可读取并补充默认参数。坏文件独立跳过并写日志。
- 算法与体素化在 `ForkJoinPool.commonPool()` 中执行；世界访问始终在服务端主线程。
- 预览参数更新防抖 50ms，取消过时任务。生成上限为 1800 节点、80000 方块。
- 服务端最多同时处理 4 项构建任务；每玩家仅 1 项；数据包请求间隔至少 500ms。
- 构建预检查和落盘共享每 tick 最多 1024 次处理及 4ms 的循环时间预算。单次 `setBlock` 的耗时不能被此预算中断。
- `2 | 16` 对应此版本的 `UPDATE_CLIENTS | UPDATE_KNOWN_SHAPE`。不通知邻居，但仍保留正常光照维护，不保证“零光照开销”。
- 仅替换空气、可替换方块和树叶；不覆盖实体方块、已有建筑或原木。预览展示完整生成结果，实际放置会跳过障碍物。
- 目标起点距玩家不超过 64 格，整棵树必须在已加载区块、世界边界和可建造高度内，并通过原版 `mayInteract` 检查。
- 第三方领地插件若不接入原版权限判断，需要单独适配；本版未声明对所有领地插件兼容。
- 每位在线玩家保存最近 5 次构建的旧状态。Undo 只恢复仍与当时放置结果一致的方块，跨维度需返回原维度；卸载区块导致未完成的还原可再次撤销。
- Undo 为内存数据，断开连接或停止服务器后清空。断线时取消未完成任务，已经放置的部分保留。
- 缩略图采用 26.3 的 TextureTarget、渲染提交与异步 GPU 回读接口，兼容新版后端；无需直接调用 OpenGL。

## 自动验证

```powershell
.\gradlew.bat --no-daemon --console plain build
```

16 项单元测试覆盖确定性与树形分枝、管道公式、17 种树冠形状、最大树冠预算、材质权重、截头圆锥/退化线段、体素覆盖优先级、四种树种与四档尺寸、极值 DNA/负种子、枝干面连通性、取消、无效参数、连续噪声、JSON 迁移与五步历史。结果位于 `build/reports/tests/test/index.html`。

## 游戏内验收清单

2026-09-30 验证记录：完整构建及 12 项单元测试通过；使用已缓存资源执行
`runClient -x downloadAssets`，日志确认 Fabric 26.3 加载本模组、启动单机世界并正常保存退出。
资源下载曾因网络失败中断，缓存启动未覆盖所有语言包。此启动检查不代表以下交互项目已全部验收。

以下场景需要实际运行游戏确认；编译和数学测试不能替代显卡、渲染后端与多人联机验证。

- 单机创造世界：获取树木杖、打开/关闭侧栏、切换全部预设与尺寸、快速拖动滑块。
- GUI 缩放与窗口尺寸：滚动后所有按钮可达，左右预览不串位，Esc 后游戏继续正常操作。
- 放置/Undo：检查原有建筑与箱子不被覆盖；连续建造 6 次后只可撤销最近 5 次；修改新树部分方块后撤销不覆盖修改。
- 网络：专用服务器两玩家同时建造、非创造玩家、服务器缺模组、超范围/未加载区块、切换维度与中途断线。
- 预设：中文名称、关闭重开、损坏 JSON、PNG 缓存、悬停旋转、F3+T 资源包重载。
- 渲染：分别在 OpenGL 与 Vulkan 下检查全息预览及 128×128 缩略图；监测 Giant 构建与撤销期间的帧率/TPS。

本目录提供本地 Beta 包与验收说明，尚未发布到外部平台。
