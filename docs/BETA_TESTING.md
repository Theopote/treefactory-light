# Treefactory Light 0.1.0-beta.1

## 环境与安装

- Minecraft **26.3**，Fabric Loader **0.19.5+**，Fabric API **0.161.0+26.3**，Java **25**。
- 将 `build/libs/treefactory-light-0.1.0-beta.1.jar` 与匹配版本的 Fabric API 放入 `mods`。
- 多人游戏需要客户端与服务器同时安装；本版为创造模式建造工具。
- 构建须使用 JDK 25。若 Gradle 仍报 Java 22，检查 `%USERPROFILE%\.gradle\gradle.properties` 中的 `org.gradle.java.home`，或用 `-Dorg.gradle.java.home=…` 覆盖。
- 主代码位于 `src/main/java/com/treefactory/light/`；客户端专用类仅由客户端入口和客户端 Mixin 加载。

## 操作

1. 在创造物品栏「工具与实用物品」中获取树木杖，或执行 `/give @s treefactory-light:tree_wand`。
2. 主手持树木杖，**右键**打开左侧抽屉（光标在侧栏内操作 UI；在侧栏外：WASD 移动，按住**鼠标中键**转视角）。**Esc** 关闭抽屉并取消未提交预览。
3. 在世界中**右键**地面方块顶面设定放置点，树木直接出现在世界中；调参时预览会更新，再右键别处会移到新位置并还原上一处。
4. **生成器**分区大致为：
   - **树干结构**：高度、树干粗细、曲折度
   - **树冠**：形状图标网格（17 种）、树冠大小、展开度、丰满度；部分形状另有纵向拉伸 / 伞层数；吸引点密度与管道指数直接显示
   - **材质**：打开侧边调色盘（六角色正方形图标页签 + 搜索网格 + 叶片比例）
   - **保存预设**：左侧名称输入框 + 右侧保存按钮
   - 底部并排：**随机种子** | **完成建造**
5. **预设库**含多种内置预设（橡/松/柳/枯及桦、樱、金合欢等）与用户保存项；悬停当前选中卡片可看旋转缩略模型。
6. 点「完成建造」后按钮会显示准备中 / 确认中，需等服务端确认成功后界面才关闭；失败会提示并可继续调整。未完成就 Esc / 断线 / 停服，预览会被清除并还原原方块。
7. **Shift + 滚轮**（侧栏关闭时）切换 S / M / L / Giant。

## 数据和运行边界

- JSON 与 128×128 PNG 缩略图：`.minecraft/config/treefactory_light/presets/`（开发环境为 `run/config/…`）。缩略图按需重新生成。
- JSON 当前为 1.1：含 canopy、六角色 palette，以及预设形态学字段（枝角倾向、下垂、顶端优势等，主要由内置预设使用，主界面不暴露）。旧版 1.0 预设可读取并补默认值。坏文件独立跳过并写日志。
- 算法与体素化在 `ForkJoinPool.commonPool()` 中执行；世界读写始终在服务端主线程。新预览请求会取消进行中的过时生成。
- 客户端预览参数防抖约 50ms，网络发送约 80ms。体素上限 80000 方块。状态栏显示生成后的实际宽、高、深。
- 服务端最多同时 4 项生成；每玩家同时仅 1 项进行中；交互预览请求间隔约 **150ms**（最新请求排队合并）。
- 预览落盘经合并队列：主线程快照，后台写 gzip；失败会重新标脏以便重试。未提交足迹写入世界目录 `treefactory_light.dat`；崩溃或停服后下次启动会还原未提交预览。
- `2 | 16` 对应 `UPDATE_CLIENTS | UPDATE_KNOWN_SHAPE`。不通知邻居，但仍有正常光照维护。
- 仅替换空气、可替换方块和树叶；不覆盖实体方块、已有建筑或原木。校验失败时不会提交残缺结构。
- 起点距玩家不超过 128 格；整棵树须在已加载区块、世界边界与可建造高度内，并通过原版 `mayInteract`。
- 普通树冠节点上限约 2800；垂柳垂枝可额外用到约 5000 节点。
- 「完成建造」后可用快捷键 **Z**（或侧栏相关入口）撤销上一棵，最多保留最近 5 次；玩家改过的格子不会被还原。撤销时若 `setBlock` 失败会保留历史并提示。
- 第三方领地插件若不走原版权限，需单独适配。
- 有轴向属性的原木按枝段主方向设 X/Y/Z；缩略图与放置共用轴向逻辑。
- 缩略图用 26.3 的 TextureTarget / 异步 GPU 回读；世界预览是服务端放方块，不是独立全息窗口。

## 游戏内验收清单

以下场景需实际运行游戏确认；编译和单元测试不能替代显卡与联机验证。

- 单机创造：树木杖、开/关抽屉、切换预设与尺寸、快速拖滑块（预览应约 150ms 量级跟手）。
- GUI 缩放与窄窗口：滚动后控件可点；Esc 关闭后游戏操作正常。
- 树冠图标网格可切换全部 17 种形状；条件显示的拉伸 / 层数滑块范围正确（拉伸可达 0.6–2.0）。
- 材质面板：六角色正方形页签、每行 8 个方块、叶片比例可读。
- 完成建造：Preparing / Finishing 状态；失败提示；成功后树木永久保留。
- 放置 / Undo：不覆盖箱子等；连续建造 6 次后只能撤销最近 5 次；改过的格子不被 Undo。未点完成就崩溃或卸载区块时，预览应被清掉。
- 网络：专用服双人同时建造、非创造、服务器缺模组、超范围 / 未加载区块、切维度与断线。
- 预设：中文名、重开、损坏 JSON、PNG 缓存、悬停旋转、F3+T 重载。
- 渲染：OpenGL（及可用时的 Vulkan）下检查缩略图与大树建造期间帧率 / TPS；开发时最小化窗口可能出现 `Cannot acquire minimized window` 警告，一般可忽略。

本目录提供本地 Beta 说明，尚未发布到外部平台。
